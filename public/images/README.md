# Imagens do site

Coloque aqui as imagens locais que serão usadas pelo novo site da Rede Software.

## Convenção recomendada

- `logo-rede.png` — logo principal
- `logo-rede-white.png` — logo para fundos escuros
- `hero-home.jpg` — imagem principal da Home
- `sgci.jpg` — imagem principal do SGCI
- `sgci-dashboard.jpg` — dashboard/mockup do SGCI
- `sistrans.jpg` — imagem principal do SISTRANS
- `sistrans-dashboard.jpg` — dashboard/mockup do SISTRANS
- `certificacao-digital.jpg` — certificação digital
- `equipe.jpg` — equipe da Rede Software
- `suporte.jpg` — suporte/atendimento
- `empresa.jpg` — estrutura/empresa
- `produtos.jpg` — produtos/equipamentos
- `parceiros.jpg` — parceiros/revendas

Você pode usar PNG, JPG, JPEG, WEBP ou SVG. Depois de adicionar os arquivos, basta ajustar os caminhos em `src/image-map.ts`.
