# SISTRANS — Page Override

## Product context

SISTRANS is operational software for traffic-management workflows. The visual language should communicate reliability, process clarity, auditability and field readiness.

## Visual decisions

- Keep the Rede Software red as the action color, never as a full-page background.
- Favor dark interface mockups or neutral product surfaces when showing operational data.
- Use compact metric groups and structured grids for complex information.
- Keep feature sections scannable; one idea per card.

## UX decisions

- Make the product's operational outcome explicit before listing features.
- Treat dashboards and screenshots as proof, not decoration.
- Do not overload the first viewport with all modules.
- Preserve visible focus and clear link/button affordances.
